# Foto tim

Taruh foto di folder ini dengan nama berikut (huruf kecil semua, ekstensi `.jpg`):

| Orang                                           | Nama berkas   |
| ----------------------------------------------- | ------------- |
| Alfian Anggara Putra Afandy                     | `alfian.jpg`  |
| Bintang Cahya Putra Gunawan                     | `bintang.jpg` |
| Auli Damayanti, S.Si., M.Si. (dosen pembimbing) | `dosen.jpg`   |

Foto tampil dengan perbandingan 4 : 5 (potret) dan dipotong dari tengah atas, jadi pakai foto
setengah badan dengan wajah di bagian atas. Ukuran yang disarankan 800 × 1000 piksel, di bawah 300 KB.

Selama foto belum ada, kotaknya menampilkan inisial.
